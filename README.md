# Viral American — Demo Storefront

## Files
- `index.html`: page structure
- `style.css`: responsive styling
- `script.js`: product filtering, search, cart, and demo newsletter interaction

## Run locally
Open `index.html` in a browser. For best results, upload all three files together to a static host.

## Publish free with GitHub Pages
1. Sign in or create an account at https://github.com/
2. Create a new public repository, for example `viral-american-store`.
3. Upload `index.html`, `style.css`, and `script.js` to the repository root.
4. Open **Settings → Pages**.
5. Under build/deployment, choose **Deploy from a branch**, select `main` and `/ (root)`, then Save.
6. Wait for the published URL shown in the Pages section.

Alternative: use https://app.netlify.com/ and deploy the folder with Netlify Drop if that option is available in your account.

## Important before real sales
This is a front-end demo. Cart and product filters work in the browser, but it does not process payments, save orders, calculate shipping, or manage inventory. Before selling, connect a trusted checkout/payment provider available in your country, add real product photos/prices and store policies, and configure order handling. Replace the demo newsletter/social links with services you actually use.
